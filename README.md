# My-repository：Xへの毎日自動投稿

`posts.txt` に書いた文章を、毎朝8時ごろ（日本時間）に1件ずつ X（旧Twitter）へ自動で投稿します。
GitHub Actions（GitHub が無料で動かしてくれる自動実行の機能）を使うので、パソコンを起動しておく必要はありません。

## ファイルの説明

| ファイル | 役割 |
| --- | --- |
| `posts.txt` | 投稿する文章のリスト。**ふだん編集するのはこのファイルだけです** |
| `post_to_x.py` | 今日の投稿を選んで X に送るプログラム |
| `.github/workflows/daily-post.yml` | 毎日決まった時間にプログラムを動かす設定 |
| `requirements.txt` | プログラムが使うライブラリ（tweepy） |

## はじめに一度だけやる設定

### 1. X の API キーを取得する

1. [X Developer Portal](https://developer.x.com/) に、投稿したいアカウントでログインして開発者登録をします。
2. アプリ（App）を作ります。
3. アプリの **User authentication settings** で、権限（App permissions）を **Read and write** にします。
   - ⚠️ 必ず次の手順4より**前**に変更してください。あとから変えた場合は、Access Token を作り直す必要があります。
4. **Keys and tokens** の画面で、次の4つを発行してメモします。
   - API Key
   - API Key Secret
   - Access Token
   - Access Token Secret

> X API の料金や無料で使える範囲は、ときどき変わります。最新の内容は Developer Portal で確認してください。

### 2. GitHub に API キーを登録する

キーはファイルに直接書かず、GitHub の「Secrets」（他人に見えない保管場所）に登録します。

1. GitHub でこのリポジトリを開き、**Settings → Secrets and variables → Actions** を選びます。
2. **New repository secret** から、次の4つを登録します。

| Name（名前） | Secret（値） |
| --- | --- |
| `X_API_KEY` | API Key |
| `X_API_SECRET` | API Key Secret |
| `X_ACCESS_TOKEN` | Access Token |
| `X_ACCESS_TOKEN_SECRET` | Access Token Secret |

### 3. 投稿を書く

`posts.txt` に投稿したい文章を書きます。

```
おはようございます！今日も一日がんばりましょう。
---
今日の一言：小さな一歩でも、毎日続ければ大きな力になります。
#毎日投稿
```

- 投稿と投稿のあいだは `---` だけの行で区切ります。
- 1つの投稿は何行でも書けます。
- `//` で始まる行はメモ扱いで、投稿されません。
- 日本語はだいたい140文字までにしてください（X では日本語1文字を2文字として数えるためです）。
- 1日1件ずつ順番に投稿され、最後まで行ったら最初に戻ります。
- X は同じ文章の連続投稿を拒否することがあるので、投稿はある程度たくさん用意するのがおすすめです。

### 4. テストしてみる

1. GitHub の **Actions** タブを開き、左側の **毎日Xに投稿** を選びます。
2. **Run workflow** を押します。
   - 「テスト実行」にチェックが入ったままだと、**投稿はせず**、今日投稿される文章を表示するだけです。
   - チェックを外して実行すると、実際に X に投稿されます。
3. 実行結果をクリックすると、どの文章が選ばれたかを確認できます。

設定が終われば、あとは毎朝自動で投稿されます。

## よくある変更

### 投稿時刻を変えたい

`.github/workflows/daily-post.yml` の `cron` の行を書き換えます。時刻は**日本時間から9時間引いた時刻（UTC）**で書きます。

| 日本時間 | 書き方 |
| --- | --- |
| 朝 8:07 | `"7 23 * * *"`（前日の23:07） |
| 昼 12:07 | `"7 3 * * *"` |
| 夜 21:07 | `"7 12 * * *"` |

GitHub が混んでいると、実行が数分〜数十分遅れることがあります。

### 自動投稿を止めたい

**Actions** タブで **毎日Xに投稿** を選び、右上の **…** から **Disable workflow** を押します。

## うまくいかないとき

- **「API キーが設定されていないため、投稿をスキップしました」と出る**: 手順2の Secrets の名前が正しいか確認してください。
- **403 エラーが出る**: アプリの権限が Read and write になっているか確認し、Access Token を作り直して Secrets を登録し直してください。
- **「投稿が長すぎます」と出る**: その投稿を短くしてください。
