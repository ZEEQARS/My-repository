## そもそも「リポジトリ」とは？

リポジトリ（repository）は、ファイルとその**変更の履歴**をまとめて保存する入れ物です。
GitHub 上のリポジトリでは、次のことができます。

| できること | 説明 |
| --- | --- |
| ファイルの保存 | コード、文章、画像などを保管できます |
| 変更履歴の記録 | 「いつ・誰が・何を変えたか」がコミットとして残ります |
| 過去の状態に戻す | 履歴があるので、以前の状態を確認したり戻したりできます |
| ブランチでの並行作業 | 本体を壊さずに、別の場所で試しに変更できます |
| 共同作業 | 他の人とファイルを共有し、プルリクエストで変更を確認し合えます |

## README.md とは？

`README.md` は、リポジトリを開いたときに GitHub のトップページに表示される説明書です。
「このリポジトリは何か」「どう使うか」を書いておくと、自分にも他の人にもわかりやすくなります。
`.md` は Markdown という書式で、`#` で見出し、`-` で箇条書きなどを書けます。
